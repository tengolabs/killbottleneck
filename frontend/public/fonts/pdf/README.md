# KB Sans / KB Serif — písma pro PDF

Latinské podmnožiny písem **Liberation Sans** a **Liberation Serif** 2.1.5 (Red Hat, Inc.;
digitalizovaná data Google Corporation), licence **SIL Open Font License 1.1** — plný text
v `LICENSE-OFL.txt`. „Liberation" je vyhrazené jméno (OFL §3), proto se upravené
(osekané) verze jmenují KB Sans / KB Serif; přejmenování dělá
`scripts/prejmenuj-fonty-pdf.py`. Používají se jen při výrobě PDF v prohlížeči
(faktury, dokumenty Kanceláře, opravy textu v PDF) a vkládají se do výsledných souborů —
OFL vkládání do dokumentů výslovně dovoluje.
